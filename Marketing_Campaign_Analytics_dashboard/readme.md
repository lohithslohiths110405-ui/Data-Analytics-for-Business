# 📊 Marketing Campaign Performance Dashboard

## 📌 Project Overview

The **Marketing Campaign Performance Dashboard** is an interactive Power BI dashboard designed to analyze and evaluate the performance of multiple marketing campaigns across different channels, campaign types, companies, and locations.

The dashboard helps management understand campaign reach, audience engagement, clicks, conversion rates, and Return on Investment (ROI). It provides meaningful insights that can support better marketing decisions and budget allocation.

---

## 🎯 Problem Statement

You are a Marketing Analyst in a digital marketing agency. Multiple marketing campaigns have been executed across different channels. Management wants to evaluate campaign performance based on impressions, clicks, conversions, engagement, and ROI.

The objective is to develop an interactive **Marketing Campaign Analytics Dashboard using Power BI** that provides meaningful campaign insights and helps management compare campaign performance, identify trends, and make better marketing decisions.

---

## 🛠️ Tools & Technologies Used

- **Power BI** – Dashboard development and data visualization
- **Power Query** – Data cleaning and transformation
- **DAX** – KPI and calculated measures
- **Microsoft Excel / CSV** – Dataset handling
- **GitHub** – Project documentation and version control

## 📂 Dataset

The dataset contains marketing campaign performance information.

### Important Fields

| Field | Description |
|---|---|
| Date | Campaign date |
| Campaign Type | Type of marketing campaign |
| Channel Used | Marketing channel used |
| Company | Company associated with the campaign |
| Location | Campaign location |
| Impressions | Number of times the campaign was displayed |
| Clicks | Number of user clicks |
| Conversion Rate | Percentage of users who converted |
| ROI | Return on Investment |
| Engagement | Audience engagement score |

---

## 🔄 Methodology

### 1. Data Collection

Marketing campaign data was collected containing campaign details and performance metrics such as impressions, clicks, conversion rate, ROI, and engagement.

### 2. Data Import

The dataset was imported into Power BI using the **Get Data** option.

### 3. Data Cleaning

The following data preparation activities were performed:

- Checked for missing values
- Checked for duplicate records
- Verified data types
- Checked numerical columns
- Verified categorical fields
- Prepared the dataset for analysis

### 4. Data Transformation

Power Query was used to prepare the data for visualization and analysis.

### 5. KPI Creation

DAX measures were created to calculate important campaign performance indicators.

### 6. Dashboard Development

Different charts, KPI cards, and slicers were created to provide an interactive campaign analysis experience.

## 📊 Dashboard Visualizations

The dashboard contains several visualizations to analyze campaign performance.

### 1. ROI Trend Over Time

A line chart is used to analyze how ROI changes over time.

**Insight:**
- ROI remains close to 5 throughout the displayed period.
- The highest visible ROI is approximately 5.03.
- ROI performance is relatively stable.

---

### 2. ROI by Location

A horizontal bar chart compares ROI across different locations.

**Locations include:**

- Miami
- Los Angeles
- Houston
- Chicago
- New York

**Insight:**

The displayed locations have very similar ROI values, indicating that there is no major geographical difference in ROI in the current dashboard view.

---

### 3. Conversion Rate by Campaign Type

A column chart compares conversion rates across different campaign types.

**Campaign Types include:**

- Influencer
- Social Media
- Display
- Search
- Email

**Insight:**

The conversion rates of the campaign types are close to 8%, showing relatively similar conversion performance.

---

### 4. Campaign Reach vs Click Performance

A scatter/bubble chart compares campaign impressions with clicks.

**Insight:**

Campaigns with similar impressions can have different click performance. This helps identify channels that are more effective at converting campaign reach into audience interaction.

---

### 5. ROI by Marketing Channel

A horizontal bar chart compares ROI across different marketing channels.

**Channels include:**

- Facebook
- Website
- Google Ads
- Email
- YouTube

## 💡 Overall Insights

- Approximately **200K campaigns** are represented in the dashboard.
- The campaigns generated approximately **1 Billion impressions**.
- The campaigns generated approximately **110 Million clicks**.
- The average conversion rate is **8.01%**.
- The average ROI is **5.00**.
- The average engagement score is **5.49**.
- ROI remains relatively stable over the displayed time period.
- The displayed locations have similar ROI performance.
- Different campaign types have similar conversion rates.
- Marketing channels show similar ROI values in the current dashboard.
- Similar campaign reach can produce different levels of clicks.
- Combining impressions, clicks, conversion rate, engagement, and ROI provides a better understanding of campaign effectiveness.
- Interactive filters allow management to perform detailed campaign analysis.

---

## 🎯 Business Recommendations

Based on the dashboard analysis:

1. Monitor ROI regularly to identify changes in campaign performance.
2. Compare impressions and clicks to understand audience response.
3. Analyze conversion rate together with ROI rather than using conversion rate alone.
4. Use campaign-type and channel-level analysis when planning future campaigns.
5. Monitor engagement along with clicks and conversions.
6. Use the dashboard filters to identify high-performing locations and campaign segments.
7. Use the combined insights to improve marketing budget allocation.
