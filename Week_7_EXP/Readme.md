# 💰 Finance KPI Dashboard

### 📊 Budget vs Actual Performance & Expense Analysis

An interactive **Finance KPI Dashboard built using Power BI** to monitor financial performance, budget utilization, expenses, and budget variance.

---

## 🎯 Problem Statement

Senior management wants to track **budget, actual expenses, budget utilization, and spending variations** across departments, regions, categories, and payment methods.

This dashboard helps management identify overspending areas and make better financial decisions.

---

## 🛠️ Tools & Technologies

- 📊 Power BI
- 🔄 Power Query
- 📁 Excel
- 📈 Data Visualization
- 🧮 DAX

---

## 📌 Key KPIs

| KPI | Value |
|---|---:|
| 💰 Total Budget | **796M** |
| 💵 Total Actual | **891M** |
| 📊 Budget Variance | **95M** |
| 📈 Budget Utilization | **111.94%** |
| ⚠️ Overspending | **11.94%** |

---

## 📊 Dashboard Analysis

### Page 1 – Finance Dashboard

The first page provides an overview of financial performance.

**Includes:**

- Total Budget
- Total Actual
- Budget Variance
- Budget Utilization %
- Overspending %
- Budget vs Actual by Department
- Monthly Budget vs Actual
- Budget vs Actual by Region
- Budget vs Actual by Year
- Interactive Year, Department, Region, and Category slicers

---

### Page 2 – Expense & Variance Analysis

The second page provides detailed expense analysis.

**Includes:**

- Actual Expense by Category
- Budget Variance by Category
- Department-wise Budget Utilization
- Actual Expense by Payment Method
- Actual Expense by Region
- Transaction Details
- Interactive filters

---

## 🔍 Key Insights

- Actual spending (**891M**) is higher than the total budget (**796M**).
- The organization has a budget variance of approximately **95M**.
- Budget utilization is **111.94%**, indicating overall overspending.
- Overall overspending is **11.94%**.
- Department-wise analysis helps identify areas with higher spending.
- Category-wise analysis highlights major expense categories.
- Regional analysis helps compare financial performance across regions.
- Payment-method analysis shows how expenses are distributed across transaction methods.
- Transaction-level details allow users to investigate individual financial records.
